# Context Documents

This folder contains source documents and reference materials that inform the shaping process. Add these files **before** generating your PRD.

## What Goes Here

- **Statements of Work (SOW)** — Contractual scope and deliverables
- **Product Briefs** — Initial product vision and high-level requirements
- **Discovery Notes** — Stakeholder interviews and research findings
- **Competitive Analysis** — Market research and competitor features
- **Technical Constraints** — Existing systems, integrations, or limitations
- **Brand Guidelines** — Visual identity and design constraints
- **Estimation Sheets** — Development estimates by feature (CSV or spreadsheet)

## How AI Assistants Use These

When generating artifacts (PRD, epics, user stories), AI assistants will reference documents in this folder to:

- Extract detailed requirements from SOW or product briefs
- Identify user stories and acceptance criteria
- Understand scope boundaries and phase definitions
- Include accurate estimates when available
- Ensure alignment with business agreements

## File Naming Suggestions

Use descriptive names that make it easy to identify documents:

```
sow_project_name_v1.md
product_brief_2024.md
discovery_notes_stakeholder_interviews.md
competitor_analysis.md
technical_constraints.md
brand_guidelines.pdf
estimates.csv
```

## Tips

- Convert Word/PDF documents to Markdown when possible for better AI parsing
- Keep documents up to date as requirements evolve
- Remove outdated versions to avoid confusion
